# 📻 La 1ère Monitor
Collecteur et dashboard de la programmation musicale du réseau La 1ère.
## Installation
pip install requests pandas
## Utilisation
python3 collecteur.py test    # Test des flux
python3 collecteur.py          # Collecte continue
python3 analyser.py            # CSV
python3 export_json.py         # JSON
python3 -m http.server 8006    # Dashboard
